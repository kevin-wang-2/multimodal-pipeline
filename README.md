# multimodal-pipeline

多模态输入管线——一个**独立的多模态预检服务**（不绑任何 agent 平台）。

媒体附件进来 → 自动产出结构化 digest（时间轴事实 + 缺口 + 可用能力清单）→ 上层 agent 自行判断信息够不够、自行挑工具（扒谱 / 指纹 / 分轨 / VLM……），这些工具可能反过来再调预检。

## 硬约束（摘自 PRD，改动请先改 PRD）

- 预检只产出**任务无关的原子事实**，不猜意图（"够不够"归上层 agent）
- 必须覆盖**全时长**：用户意图可能藏在另一段时间里
- 关键路径必须有**本地保底**；远端（GPU 机器 / 云端）只是提质或加速，不是依赖
- 时间轴统一：**秒**、`[start, end)`、左闭右开
- 换引擎必须改缓存键（hash + 引擎档位），否则升级路径会被缓存堵死
